A universal route for the AI Family

Dr. Z and ChatGPT · November 20, 2026

Different AI agents have different access to tabs, files, scheduled tasks, and external services. A universal tracker cannot assume that every agent can read the same account. It can, however, ask every agent to produce the same portable record.

The common packet

The portable schema carries a CT identifier, provider, agent, title, project, timestamps, summary, decisions, next action, status, chat links, and archive information. A handoff adds the source, target, and the context needed to continue.

Four levels of automation

  1. Manual but portable. An agent produces a JSON or spreadsheet record for the user to import.
  2. Browser assisted. A helper captures the active title and URL after an explicit user action.
  3. Provider connected. An authorized API, connector, or extension retrieves supported metadata or exports.
  4. Shared service. A Cloudflare-hosted API or MCP service synchronizes records and archives across agents and devices.

ChatGPT Spaces and the neutral gateway

ChatGPT Spaces can serve as the immediate mission control layer for shared plans and reference pages. A neutral gateway is still needed for agents outside ChatGPT. The two layers are complementary: Spaces organizes the current work, while the gateway carries portable records among providers.

Minimum adapter interface

What this POP proves

Universal does not have to mean identical access. It can mean a shared record, honest capability labels, and predictable handoffs. Each AI Family member can contribute at the level its tools permit without breaking the common ledger.
